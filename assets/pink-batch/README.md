# Pink batch

Drop new soft pink background photos here, in any file name and format. This folder is not published. Each photo is converted to webp, moved into its folder under public/images, and the old photo it replaces is deleted in the same change.

## Waiting for a pink version

None. Every photo on the site has its soft pink version.

Landscape photos at least 2500px wide, portrait and square at least 1200px wide.

## Staying

Soft pink or black backgrounds: banners/rose-dress-banner.webp, banners/mocha-romper-banner.webp. banners/blue-romper-banner.webp already carries its soft pink version. The seven products/ cutouts sit on the site's pink frames and stay too.
