[major] The bc_cart cookie is unsigned, so a script can send its own Cookie header with any cart id and still make the site query Shopify; the cookie does not stop scripted calls.
[major] startCheckout has no throttle, so a script can loop it to create Shopify carts and collect a valid pass for each; only a rate limit stops scripted load on either action.
[minor] orderPlaced deletes the cookie before the browser forgets its saved cart, so a reload in between leaves bought pieces in the bag until the cookie would have expired.
[minor] secure: true stops Safari on http://localhost and phones on a LAN address from storing the cookie, so the bag never empties after a test checkout in dev.
[minor] The test for a non-cart id now passes on the cookie mismatch alone, so it no longer proves the cart id format check.
[minor] No test proves a cart id containing ?key= survives cookie encoding and decoding.
[minor] Deleting a cookie in orderPlaced on page load makes Next refresh the page's server components once per confirmed order.
